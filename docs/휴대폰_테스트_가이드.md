# 휴대폰으로 테스트하기

**받는 곳**: [Releases 최신 버전](https://github.com/728haven-oss/road-docent/releases/latest) → Assets → `RoadDocent_v*.apk`

**준비**
- Android 13 이상 (minSdk 33). 세로·가로 모두 됩니다.
- APK 설치 → "출처를 알 수 없는 앱" 허용 (시연용 키로 서명돼 있어 Play 프로텍트 경고가 뜨면 "무시하고 설치"). 이전 버전이 있으면 지우고 설치하세요.
- 설정 → TTS(텍스트 음성 변환) → Google 음성 서비스에 한국어 음성 데이터가 설치돼 있어야 소리가 납니다.
- 마이크 권한은 음성 명령(🎤)용입니다. 거부해도 버튼으로 모두 동작합니다.

**3분 데모 순서**
1. 로그인 **test / 1234** → 약관 두 항목 동의 → 처음 한 번 언어·탑승자·좋아하는 여행 선택
2. 연결 화면에서 **시뮬레이션 · 데모**
3. 홈 → 코스 카드 **▶ 이 코스로 출발** (예: 인천공항 → 경복궁). 목적지와 경로 지도가 뜨고 가이드가 탑승합니다.
4. 이야기를 듣다가 **⏮ 이전 · 🔁 다시 듣기 · 다음 ⏭**, ➕ 자세히(심화 역사편)
5. 상단 **🧒 키즈** → 이야기 두 편마다 창밖 퀴즈, 10초 안에 번호를 누르거나 "2번"·"이순신 장군"처럼 말하기
6. **⋮ → 🎬 시연 컨트롤**: 자동 시연 · 30분 앞으로 · 정체 발생 · 도착·주차 · 다시 출발 · 뒷좌석 탑승
7. 도착·주차 → "여기서 할 일" 카드 → 다시 출발 → "다음은 어디?" → 장소를 누르면 이야기 카드, **🚗 여기로 출발**
8. **⋮ → 🗺 오늘의 여행 일지**

**실제 위치로 테스트**: 연결 화면에서 **📍 휴대폰 GPS · 실제 위치** → 위치 권한 허용 → 코스 선택. 이야기 지점 반경에 들어가면 해설이 나오고, 목적지 근처에서 멈추면 도착 안내, 다시 움직이면 "다음은 어디?"가 뜹니다.

**알려진 제약**
- 가족 목소리(음성 복제)는 설정에 API 키를 넣어야 동작하고, 없으면 기기 TTS로 읽습니다.
- 전화 예약은 번호가 있는 장소에서만 켜집니다.

**이상하면 적어 주세요**: 어느 화면에서, 무슨 말이 나왔고, 뭐가 어색했는지.
