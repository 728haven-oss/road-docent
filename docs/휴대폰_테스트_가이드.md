# 휴대폰으로 테스트하기 (연동 전 완성본 APK)

**받는 곳**: GitHub → Releases (Actions 탭에서 "Build & Release APK" → Run workflow에 버전을 넣으면 새 릴리즈가 생깁니다). 저장소의 `apk/` 폴더에도 같은 파일이 있습니다.

**준비**
- Android 13 이상 (minSdk 33). 가로 화면 고정이라 폰을 눕혀서 보세요.
- [Releases 최신 버전](https://github.com/728haven-oss/road-docent/releases/latest)에서 APK를 폰에 받아 설치 → "출처를 알 수 없는 앱" 허용 (데모용 키로 서명돼 있어 Play 프로텍트 경고가 뜨면 "무시하고 설치").
- 설정 → 일반 → TTS(텍스트 음성 변환) → Google 음성 서비스 → 한국어·영어 음성 데이터가 설치돼 있어야 합니다 (없으면 소리가 안 나거나 영어 억양으로 읽습니다).
- 첫 실행 때 마이크 권한 → 허용 (음성 명령 🎤용. 거부해도 버튼으로 전부 동작).

**v0.2.1 변경** — 화면 회전 지원(세로에서는 패널이 위아래로 쌓이고 스크롤), 📍 휴대폰 GPS 모드(실제 위치로 길목 해설·도착·재탑승), ▶ 시연 버튼(시간이 빨리 흐르다 장소를 지날 때 멈추고 설명), 시도 경계 진입 해설(경기→강원, 인천→서울), 녹음 실패 시 이유 표시(마이크 권한). 새 차·충전은 ⚙ 설정 맨 아래 "부가 기능"으로 분리(기본 꺼짐).

**실제 위치로 테스트**: 연결 화면에서 "📍 휴대폰 GPS" → 위치 권한 허용 → 목적지(예: 경복궁) 선택. 광화문·남대문 반경에 실제로 들어가면 해설이 나오고, 150m 안에서 90초 정지하면 도착·"여기서 할 일", 다시 움직이면 "다음은 어디?"가 뜹니다. 목적지 없이 🪟 창밖을 누르면 지나는 곳마다 이야기가 나옵니다.

**순서 (5분 데모 그대로)**
1. 온보딩 3탭: 한국어 → 아이와 함께 → 🏯 역사 → 시작
2. 연결 화면에서 **시뮬레이터** 선택 (Pleos 연동은 Pleos Connect AVD/실차에서만)
3. 첫 화면 오른쪽 "출발 전 알아두기" 확인 → **인천공항 → 경복궁** 출발
4. 가이드가 말하면 그냥 두기(2.5초 뒤 자동 이어짐). 퀴즈 카드가 뜨면 8초 기다리거나 "더 자세히" 버튼
5. 데모 바: ⏩ 빨리감기 → 남대문·광화문 길목 해설 / 🚗 정체 → 긴 이야기 / 🧒 뒷좌석 → 키즈 모드
6. ⏩ → 도착 15분 전 브리핑 → 📞 예약 (전화 앱 열림)
7. 🏁 도착·P → "여기서 할 일" 9단계 + 📱 오디 인계 버튼
8. ▶ D 재출발 → "다음은 어디?" → 첫 번째 카드(국립중앙박물관) → 가이드가 이어서 25분 코스 시작
9. 🗺 일지 → 📤 오늘의 여행 공유 (이미지 카드가 공유 시트로)
10. 🪟 창밖 모드, 🔌 충전, 📱 동승자(QR은 폰이 핫스팟/같은 Wi-Fi일 때 다른 폰으로 접속), ⚙ 설정 → 🚗 새 차 알아가기 켜고 아무 목적지나 출발

**알려진 제약**
- 시뮬레이터는 1분 = 실제 1초 배속. 실제 GPS는 쓰지 않습니다(Pleos NaviHelper가 그 역할).
- 음성 복제(가족 목소리)는 설정에 API 키를 넣어야 실제 복제가 되고, 없으면 기기 TTS로 재생됩니다.
- 전화 예약은 번호가 있는 장소에서만 📞가 켜집니다.

**이상하면 적어 주세요**: 어느 단계에서, 무슨 말이 나왔고, 뭐가 어색했는지. 콘텐츠는 `app/src/main/assets/guides/*.json`만 고치면 됩니다.
