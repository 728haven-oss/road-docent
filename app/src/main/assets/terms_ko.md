# 로드 도슨트 이용약관 및 개인정보 처리방침 (테스트 빌드, 2026-10-26)

## 1. 서비스
로드 도슨트는 차량 내비게이션 목적지와 주행 신호를 바탕으로 지역 해설을 음성으로 제공하는 앱입니다. 본 빌드는 현대자동차그룹 차량용 앱 개발 공모전 심사·테스트용이며 상용 서비스가 아닙니다.

## 2. 안전
- 해설은 운전 보조가 아니라 동승 가이드입니다. 운전 중 화면 조작은 하지 마세요. 음성 명령 또는 정차 후 조작을 권장합니다.
- 시속 100km 이상 등 안전 기준에서는 해설이 자동으로 멈춥니다.
- 해설 내용(운영시간·요금·도로 규정 등)은 출발 당일 공식 안내로 다시 확인하세요.

## 3. 수집하는 정보와 보관
- 계정: 아이디·표시 이름·이메일(구글 로그인 시). 기기에만 저장됩니다.
- 위치·주행 기록: 해설 재생과 여행 일지 작성에만 사용하며 기기에만 보관됩니다. 서버로 전송하지 않습니다. 설정에서 "여행 일지 저장 안 함"을 선택하면 보관하지 않습니다.
- 음성 녹음(가족 목소리): 사용자가 직접 녹음한 경우에만, 앱 내부 저장소에 보관되며 삭제 버튼으로 즉시 삭제됩니다. 음성 복제 API 키를 입력한 경우에만 해당 제공자로 전송됩니다.
- 마이크(음성 명령)·위치 권한은 거부해도 버튼으로 모든 기능을 쓸 수 있습니다.

## 4. 아동
14세 미만 아동의 목소리 녹음은 보호자 동의 체크가 필요하며, 키즈 모드 콘텐츠는 교육·놀이 목적입니다.

## 5. 콘텐츠 출처
해설은 국가유산청·한국관광공사(관광 스토리텔링 DB, 공공누리)·지자체 공개 자료·공개된 여행 크리에이터 영상 정보를 바탕으로 작성되었으며, 각 에피소드에 출처가 표기됩니다. 오류 신고는 앱의 👎 버튼으로 가능합니다.

## 6. 변경
약관이 바뀌면 다음 로그인 때 다시 안내하고 동의를 받습니다.
